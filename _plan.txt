План реализации

1. Создать консольный скрипт с аргументом URL.
   - сохранять результаты в текущую рабочую директорию;
   - для промежуточной загрузки использовать временный файл в текущей
     рабочей директории;
2. Определять имя файла-результата:
   - для каждой загрузки использовать имя, переданное в конкретном HTTP-ответе, если оно есть;
   - если в ответе есть корректное значение `filename*`, использовать его;
     декодировать percent-encoding согласно указанной кодировке (обычно
     UTF-8), а затем санитаризировать;
   - если `filename*` отсутствует или некорректно, использовать `filename`
     без URL-декодирования, а затем санитаризировать;
   - имя из Content-Disposition предварительно санитаризировать: после
     декодирования взять последний непустой сегмент пути и заменить только
     опасные для имени файла символы на `_`, сохраняя остальные допустимые
     символы;
   - если имени в HTTP-ответе нет — взять последний непустой сегмент URL;
   - выбранное имя санитаризировать; если URL не содержит непустого сегмента
     или после санитаризации имя получилось пустым/состоящим только из
     опасных символов — использовать `download`;
   - имя определяется заново для каждой загрузки, поэтому разные HTTP-ответы могут сохраняться в разные файлы.
3. Для каждого из 10 последовательных запросов:
   - выполнять запрос;
   - при ошибке запроса измерить время этой попытки, вывести сообщение и перейти к следующему запросу;
   - считать HTTP-ошибкой любой ответ с неуспешным HTTP-кодом;
   - при HTTP-ошибке не считать тело ошибки скачанными данными и не создавать
     файл-результат;
   - для успешного ответа потоково сохранять тело во временный файл;
   - переименовывать временный файл в выбранный файл-результат только после
     успешного полного скачивания; существующий файл-результат заменять;
   - считать объём фактически полученных данных, в том числе при прерванной загрузке;
   - измерять только время скачивания каждой попытки, в том числе прерванной
     или завершившейся HTTP-ошибкой; не включать время работы с файловой
     системой и прочие операции;
   - показывать текущую скорость в десятичных МБ/с (1 МБ = 1 000 000
     байт), обновляя значение в той же строке; для загрузки, которая не
     началась, скорость не выводить;
4. После каждой попытки закрывать открытый файл, чтобы данные были полностью записаны на диск.
5. После всех 10 загрузок вывести:
   - среднее время всех 10 попыток скачивания, включая завершившиеся ошибкой;
   - общий объём скачанных данных в байтах;
   - итоговую информацию о сохранённых файлах.
6. Добавить обработку ошибок HTTP, некорректного URL, отсутствующего имени файла и прерванного скачивания. Принимать URL только со схемой `http` или `https`.
   - при `Ctrl+C` немедленно прервать все 10 попыток;
   - частично скачанный временный файл при прерывании оставить на диске;
   - временный файл ответа с HTTP-ошибкой удалить, файл-результат не создавать;
   - для имени из URL декодировать URL-кодирование перед санитаризацией;
     для параметра `filename` URL-декодирование не выполнять; некорректные
     последовательности считать небезопасными и заменять на `_`;
   - в URL и `Content-Disposition` обрабатывать `/` и `\\` как разделители
     пути, брать последний непустой сегмент; сегменты `.` и `..` не имеют
     специального значения;
   - после санитаризации пустые имена и имена, состоящие только из опасных
     символов, заменять на `download`;
   - считать `filename*` некорректным при неизвестной кодировке, ошибочном
     percent-encoding или пустом значении; в этих случаях использовать
     `filename` без URL-декодирования.
7. Проверить скрипт на синтаксис и базовый запуск.
8. Использовать только стандартную библиотеку Python 3.12.3, без внешних зависимостей:
   - `argparse` — разбор аргумента URL и параметров командной строки;
   - `urllib.request` — выполнение HTTP-запросов и потоковое чтение ответа;
   - `urllib.parse` — извлечение последнего сегмента из URL;
   - `email.message` — разбор параметров заголовка `Content-Disposition`;
   - `pathlib` — работа с путём целевого файла;
   - `tempfile` — создание временного файла в текущей директории;
   - `time` — измерение длительности скачивания;
   - `sys` — обновление строки прогресса и вывод сообщений об ошибках.
