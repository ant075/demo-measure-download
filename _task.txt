Напиши консольный скрипт на Python версии 3.12.3. Скрипт:
 - принимает адрес, к которому стучаться (например, тяжёлая картинка);
 - делает к нему 10 запросов последовательно и дожидается полного ответа на каждый;
 - сохраняет результат каждого скачивания непосредственно в один и тот же файл `download` в текущей рабочей директории; имя из URL и HTTP-ответа не используется
 - считает среднее время запроса и общий объём скачанных данных в байтах, печатает их в консоли по окончании всех загрузок;
 - печатает в консоль скорость скачивания в мегабайтах в секунду (МБ/с) в процессе скачивания; каждое значение не на новой строке, а на месте предыдущего.

Среднее время считается по всем 10 попыткам, включая ошибки. При ошибке HTTP тело ошибки не считается скачанными данными. Для загрузки, которая не началась, скорость не выводится.
Временный файл не используется: после успешного HTTP-ответа тело записывается непосредственно в `download`. При HTTP-ошибке файл не создаётся и не изменяется; при прерванной после начала загрузке частично записанный файл `download` сохраняется.
